# WorldFatherJS
WorldFatherJS is a JS/TS web based game rendering engine.

- The current version is: **WorldFather2DC**
- Last update: **31/08/2026**

Documentation on how to initialise and use will be added when WorldFather2DC is updated to a stable state with features from 2DA / 2DB that have currenrtly not been reimplemented (Likely will be renamed to *WorldFatherJS* at this point).

---

- WorldFather2DA is the original "Alpha".
	- Contains A1 / A3 / A4 / AX for future reference.
- WorldFather2DB is the original "Beta".
	- Contains WorldFatherX for future reference.
- WorldFather2DC is the current development version of WorldFatherJS.
	- Created when I wanted to swap to TypeScript in order to learn TypeScript and have access to features I was interested in.
